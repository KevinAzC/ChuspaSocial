# Criterios de Salida

## Para pasar de dev a main

- [ ] Cobertura de tests >= 70 %
- [ ] Cero bugs de severidad Crítica o Alta abiertos
- [ ] Todos los casos de prueba del sprint ejecutados
- [ ] Informe de pruebas generado y aprobado
- [ ] Revisión de seguridad completada
- [ ] Documentación actualizada

## Umbrales cuantitativos de aceptación

| Criterio | Umbral requerido |
|---|---|
| Pruebas críticas | 100 % ejecutadas y aprobadas |
| Defectos de seguridad bloqueantes | 0 abiertos |

El release no puede autorizarse mientras exista una prueba crítica fallida o un defecto de seguridad bloqueante abierto.
